08 / SAMMLUNGEN ANLEGEN

Viele Werte.
Ein Array.

Ein Array speichert mehrere Werte in einer geordneten Liste. Arrays eignen sich für Namen, Aufgaben, Produkte und viele andere Sammlungen.

Einsteiger·Index, Länge und grundlegende Methoden

Elemente lesen und verändern

Der erste Eintrag steht am Index 0. Mit length erhältst du die Anzahl der Einträge; der letzte Index ist also length - 1.

const farben = ["Lila", "Grün", "Orange"];
console.log(farben[0]);          // Lila
console.log(farben.length);      // 3
console.log(farben[farben.length - 1]); // Orange

Einträge hinzufügen und entfernen

push() fügt am Ende ein, pop() entfernt das letzte Element. unshift() und shift() arbeiten am Anfang.

const aufgaben = ["HTML lernen", "Pause machen"];
aufgaben.push("JavaScript üben");
const letzteAufgabe = aufgaben.pop();
console.log(aufgaben); // ["HTML lernen", "Pause machen"]

Arrays können mit for...of elementweise durchlaufen werden.

Merke: Ein Array ist nullbasiert: Das erste Element hat Index 0. Für viele Aufgaben gibt es spezielle Array-Methoden, die im nächsten Thema vorkommen.
