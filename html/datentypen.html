03 / DATEN VERSTEHEN

Jeder Wert
hat einen Typ.

Datentypen beschreiben, welche Art von Wert du verwendest. Sie entscheiden zum Beispiel, ob JavaScript rechnen oder Text verbinden soll.

Einsteiger·Primitive Werte und Typumwandlung

Häufige Datentypen

  • string — Text, zum Beispiel "Hallo"
  • number — ganze Zahlen und Kommazahlen, zum Beispiel 42 oder 3.14
  • boolean — wahr oder falsch: true / false
  • undefined — ein Wert wurde noch nicht festgelegt
  • null — absichtlich kein Wert
const titel = "JS Studio"; // string
const kapitel = 4;          // number
const fertig = false;       // boolean
console.log(typeof titel);  // "string"

Auf Typen achten

Mit dem Pluszeichen kann JavaScript Zahlen addieren oder Texte zusammenfügen. Eine Eingabe aus einem HTML-Feld ist zunächst Text — auch dann, wenn darin Ziffern stehen.

console.log(2 + 3);       // 5
console.log("2" + 3);     // "23"
console.log(Number("2") + 3); // 5

Number(), String() und Boolean() wandeln Werte in einen anderen Typ um. Prüfe Eingaben, bevor du mit ihnen rechnest.

Merke: typeof hilft beim Untersuchen eines Wertes. Beachte: typeof null ergibt aus historischen Gründen "object".
