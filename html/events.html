13 / AUF AKTIONEN REAGIEREN

Ein Klick.
Eine Reaktion.

Ereignisse (Events) melden, dass etwas passiert ist — etwa ein Klick, eine Texteingabe oder das Absenden eines Formulars. Mit Event-Listenern reagiert dein Code darauf.

Webentwicklung·click, input und submit

Einen Klick abfangen

addEventListener() verbindet ein Element mit einem Ereignis und einer Funktion, die beim Ereignis ausgeführt wird.

const knopf = document.querySelector("button");
const ausgabe = document.querySelector("p");

knopf.addEventListener("click", () => {
  ausgabe.textContent = "Du hast geklickt!";
});

Eingaben beobachten

Das input-Ereignis wird ausgelöst, während sich der Feldinhalt verändert. Beim Formularereignis submit kannst du den Standard-Seitenwechsel verhindern.

const feld = document.querySelector("input");
feld.addEventListener("input", (event) => {
  console.log(event.currentTarget.value);
});

Der Event-Parameter enthält Informationen zum Ereignis. event.currentTarget ist das Element, an dem der Listener registriert wurde.

Merke: Bevorzuge addEventListener() gegenüber Inline-Attributen wie onclick. So bleiben Verhalten und HTML sauber getrennt.
