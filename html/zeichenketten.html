16 / MIT TEXT ARBEITEN

Text hat
Werkzeuge.

Strings sind Textwerte. Ihre eingebauten Methoden helfen dir, Leerzeichen zu entfernen, Schreibweisen anzupassen, Inhalte zu suchen oder Teile herauszunehmen.

JavaScript-Methoden·String, includes und replaceAll

Text prüfen und anpassen

trim() entfernt Leerzeichen am Anfang und Ende. toLowerCase() und toUpperCase() ändern die Großschreibung. includes() prüft, ob ein Teiltext vorkommt.

const eingabe = "  JavaScript  ";
const sauber = eingabe.trim();
console.log(sauber.toUpperCase()); // JAVASCRIPT
console.log(sauber.includes("Script")); // true

Teile finden und ersetzen

slice() gibt einen Teilstring zurück. replaceAll() ersetzt alle Vorkommen eines Textes.

const satz = "Lerne HTML und HTML";
console.log(satz.slice(6, 10)); // HTML
console.log(satz.replaceAll("HTML", "JS"));

Strings sind unveränderlich: Methoden liefern in der Regel einen neuen String zurück. Der ursprüngliche Wert bleibt gleich, solange du das Ergebnis nicht speicherst.

Merke: Methoden werden mit Punktnotation aufgerufen, zum Beispiel text.trim(). Die Klammern sind nötig, weil es sich um einen Funktionsaufruf handelt.
