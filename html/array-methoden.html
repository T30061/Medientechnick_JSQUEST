09 / ARRAYS BEARBEITEN

Die nützlichsten
Array-Methoden.

Array-Methoden filtern, verändern oder untersuchen Listen. Die Methoden map(), filter() und find() sind besonders häufig im Einsatz.

Fortgeschrittene Grundlagen·map, filter, find und reduce

Aus jedem Eintrag etwas machen: map()

map() ruft eine Funktion für jedes Element auf und liefert ein neues Array zurück.

const preise = [10, 20, 30];
const mitSteuer = preise.map(preis => preis * 1.19);
console.log(mitSteuer); // [11.9, 23.8, 35.7]

Auswahl treffen: filter() und find()

filter() sammelt alle Elemente, die eine Bedingung erfüllen. find() gibt nur das erste passende Element zurück.

const punkte = [4, 12, 7, 20];
const hohePunkte = punkte.filter(punkt => punkt >= 10);
const ersterTreffer = punkte.find(punkt => punkt > 10);
// hohePunkte: [12, 20]; ersterTreffer: 12

Auf einen Wert reduzieren: reduce()

reduce() kombiniert die Elemente zu einem einzelnen Ergebnis, zum Beispiel einer Summe. Der Startwert steht als zweites Argument.

const summe = [4, 12, 7].reduce(
  (gesamt, zahl) => gesamt + zahl,
  0
);
console.log(summe); // 23

Merke: map() erstellt eine umgewandelte Liste, filter() eine Auswahl und find() einen einzelnen Treffer. Sie verändern das ursprüngliche Array nicht.
