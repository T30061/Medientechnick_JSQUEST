02 / WERTE SPEICHERN

Variablen &
Konstanten.

Variablen geben Werten einen Namen. So kannst du Daten speichern, später wiederverwenden und in deinem Programm verändern.

Einsteiger·let, const und Gültigkeitsbereiche

Werte benennen

Verwende const, wenn eine Variable später nicht neu zugewiesen werden soll. Nutze let, wenn sich der gespeicherte Wert ändern muss. var ist eine ältere Schreibweise und wird in neuem Code meist vermieden.

const vorname = "Mila";
let punkte = 0;
punkte = punkte + 10;

console.log(vorname, punkte); // Mila 10

Gute Namen wählen

Namen sollten erklären, was gespeichert wird. JavaScript-Entwickler:innen verwenden oft camelCase: Das erste Wort beginnt klein, weitere Wörter beginnen groß.

const lieblingsFarbe = "Violett";
let istEingeloggt = false;

Ein konstanter Variablenname bedeutet nicht automatisch, dass ein Objekt unveränderlich ist — const verhindert nur die Neuzuweisung der Variablen.

Merke: Standardmäßig const verwenden. Erst zu let wechseln, wenn du tatsächlich einen neuen Wert zuweisen musst.
