01 / ERSTE SCHRITTE

Hallo,
JavaScript.

JavaScript (kurz JS) ist eine Programmiersprache, mit der du Webseiten interaktiv machst. HTML gibt einer Seite Struktur, CSS gestaltet sie — JavaScript lässt sie reagieren.

Einsteiger·Syntax und erste Ausgabe

Dein erstes Programm

Eine Anweisung ist ein einzelner Schritt, den der Browser ausführt. Mit console.log() schreibst du eine Nachricht in die Entwicklerkonsole des Browsers.

console.log("Hallo, Web!");
console.log(2 + 3);

Öffne die Entwicklerwerkzeuge deines Browsers (meist F12) und wähle den Tab „Konsole“, um die Ausgabe zu sehen.

Die wichtigsten Schreibregeln

  • JavaScript unterscheidet Groß- und Kleinschreibung: name und Name sind verschieden.
  • Text steht in Anführungszeichen; Zahlen kannst du direkt schreiben.
  • Ein Semikolon am Ende einer Anweisung ist sinnvoll und macht das Ende deutlich.
  • Mit // schreibst du einen Kommentar, den JavaScript nicht ausführt.
// Das ist ein Kommentar
console.log("Los geht's!");

Merke: JavaScript läuft im Browser. Verknüpfe eine Datei über <script src="js/index.js" defer></script> mit deiner HTML-Seite.
