20 / CODE AUFTEILEN

Module:
Ordnung im Projekt.

Module teilen ein größeres JavaScript-Projekt in Dateien mit klaren Aufgaben. Du kannst Funktionen und Werte gezielt exportieren und in anderen Dateien importieren.

Fortgeschrittene Grundlagen·export und import

Benannte Exporte

In rechner.js exportierst du genau die Funktion, die andere Dateien verwenden dürfen.

// rechner.js
export function addiere(a, b) {
  return a + b;
}

Importieren und im Browser starten

Eine andere Datei importiert den benannten Export. Damit der Browser Module erkennt, erhält das Script-Element den Typ module.

// app.js
import { addiere } from "./rechner.js";
console.log(addiere(2, 3));

// in der HTML-Datei:
<script type="module" src="./app.js"></script>

Module laufen automatisch im strikten Modus und haben ihren eigenen Gültigkeitsbereich. Beim Testen kann ein lokaler Entwicklungsserver nötig sein.

Merke: Halte Module klein und thematisch zusammenhängend. Exportiere nur, was andere Teile des Projekts wirklich brauchen.
