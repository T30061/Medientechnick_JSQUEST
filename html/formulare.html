14 / EINGABEN VERARBEITEN

Formulare,
die antworten.

HTML-Formulare sammeln Eingaben. JavaScript kann diese prüfen, verarbeiten und dem Nutzer direkt eine Rückmeldung geben.

Webentwicklung·FormData und Validierung

HTML übernimmt die Basisprüfung

Nutze HTML-Attribute wie required, type="email" und minlength. Damit funktioniert eine Grundvalidierung sogar dann, wenn JavaScript deaktiviert ist.

<form id="kontakt">
  <label for="email">E-Mail</label>
  <input id="email" name="email" type="email" required>
  <button>Absenden</button>
</form>

Formular mit JavaScript auslesen

Fange submit ab und nutze FormData, um die Felder über ihre name-Attribute auszulesen.

const formular = document.querySelector("#kontakt");
formular.addEventListener("submit", (event) => {
  event.preventDefault();
  const daten = new FormData(formular);
  const email = daten.get("email").trim();
  console.log("E-Mail:", email);
});

Bei echten Anwendungen müssen Daten zusätzlich auf dem Server geprüft werden. Browser-Prüfungen allein sind keine Sicherheitsgrenze.

Merke: Labels machen Felder verständlicher und zugänglicher. Verbinde jedes <label for> mit der passenden ID des Eingabefeldes.
