18 / DATEN IM BROWSER BEHALTEN

Merken über
den Seitenwechsel.

Mit Web Storage kann eine Seite kleine Daten lokal im Browser speichern. localStorage bleibt nach dem Schließen des Tabs erhalten; sessionStorage gilt nur für die aktuelle Sitzung.

Browser-API·localStorage und JSON

Einfache Werte speichern

Web Storage speichert Schlüssel und Werte als Text. Die Methoden setItem(), getItem() und removeItem() verwalten diese Einträge.

localStorage.setItem("thema", "dark");
const thema = localStorage.getItem("thema");
console.log(thema); // dark
localStorage.removeItem("thema");

Objekte als JSON speichern

Objekte und Arrays müssen vor dem Speichern in Text umgewandelt werden. JSON.stringify() wandelt in JSON-Text um und JSON.parse() liest ihn zurück.

const profil = { name: "Mila", level: 2 };
localStorage.setItem("profil", JSON.stringify(profil));

const gespeichert = localStorage.getItem("profil");
const geladen = gespeichert ? JSON.parse(gespeichert) : null;

Beim Lesen von extern veränderbaren Daten sollte ungültiges JSON abgefangen und behandelt werden.

Wichtig: Speichere keine Passwörter, geheimen Schlüssel oder vertraulichen Daten in Web Storage. JavaScript auf derselben Seite kann diese Werte lesen.
