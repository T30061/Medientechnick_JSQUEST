07 / CODE WIEDERVERWENDEN

Funktionen:
einmal bauen.

Eine Funktion bündelt Anweisungen unter einem Namen. Du kannst sie aufrufen, Werte übergeben und ein Ergebnis zurückgeben lassen.

Einsteiger·Parameter, Rückgabewerte, Pfeilfunktionen

Funktion deklarieren

Parameter sind Eingaben einer Funktion. return gibt ein Ergebnis zurück und beendet die Funktion.

function begruessung(name) {
  return `Hallo, ${name}!`;
}

const nachricht = begruessung("Mila");
console.log(nachricht); // Hallo, Mila!

Pfeilfunktionen

Für kurze Funktionen ist die Pfeilschreibweise (Arrow Function) praktisch. Wenn der Funktionskörper nur einen Ausdruck enthält, kann die geschweifte Klammer entfallen.

const verdoppeln = (zahl) => zahl * 2;
const quadrat = zahl => zahl * zahl;

console.log(verdoppeln(4)); // 8

Funktionen können Werte erwarten, Werte zurückgeben oder auch eine Aktion ausführen, zum Beispiel auf einen Klick reagieren.

Merke: Ein Parameter ist der Platzhalter in der Funktionsdefinition; ein Argument ist der konkrete Wert, den du beim Aufruf übergibst.
