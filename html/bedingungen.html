05 / ENTSCHEIDUNGEN TREFFEN

Wenn das,
dann jenes.

Mit Bedingungen lässt du dein Programm unterschiedliche Wege nehmen — abhängig davon, ob eine Aussage wahr oder falsch ist.

Einsteiger·if, else und switch

if und else

Der Code im if-Block läuft nur, wenn die Bedingung wahr ist. else beschreibt, was sonst passieren soll. Mit else if prüfst du weitere Fälle.

const temperatur = 22;

if (temperatur > 25) {
  console.log("Warm!");
} else if (temperatur >= 15) {
  console.log("Angenehm.");
} else {
  console.log("Zieh eine Jacke an.");
}

Mehrere Fälle mit switch

switch ist hilfreich, wenn du denselben Wert mit mehreren konkreten Möglichkeiten vergleichst. Ein break verhindert, dass der nächste Fall ebenfalls ausgeführt wird.

const tag = "Samstag";
switch (tag) {
  case "Samstag":
  case "Sonntag":
    console.log("Wochenende!");
    break;
  default:
    console.log("Zeit für den Alltag.");
}

Merke: Bedingungen sollten zu einem klaren Wahrheitswert führen. Ein einzelnes Gleichheitszeichen (=) weist zu; für Vergleiche brauchst du ===.
