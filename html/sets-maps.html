11 / SAMMLUNGEN SPEZIALISIERT VERWALTEN

Mehr als Array
und Objekt.

JavaScript bietet Set und Map für besondere Sammlungen: eindeutige Werte oder Schlüssel-Wert-Paare mit flexiblen Schlüsseltypen.

Fortgeschrittene Grundlagen·Set, Map und häufige Methoden

Set: nur eindeutige Werte

Ein Set speichert jeden Wert höchstens einmal. Es eignet sich zum Entfernen von Duplikaten oder für schnelle Mitgliedschaftsprüfungen.

const tags = new Set(["js", "web", "js"]);
tags.add("lernen");
console.log(tags.has("web")); // true
console.log([...tags]);       // ["js", "web", "lernen"]

Map: Schlüssel und Werte

Eine Map speichert Zuordnungen. Anders als bei einem Objekt können Schlüssel jeden Datentyp haben. Nützliche Methoden sind set(), get(), has() und delete().

const punkte = new Map();
punkte.set("Mila", 12);
punkte.set("Noah", 9);
console.log(punkte.get("Mila")); // 12
console.log(punkte.size);        // 2

Merke: Nutze ein Array für eine geordnete Liste, ein Set für eindeutige Werte und eine Map für eine Sammlung von Schlüssel-Wert-Zuordnungen.
