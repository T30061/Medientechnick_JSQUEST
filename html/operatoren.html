04 / MIT WERTEN ARBEITEN

Rechnen,
vergleichen, prüfen.

Operatoren verknüpfen Werte miteinander. Sie helfen dir zu rechnen, Bedingungen zu vergleichen und mehrere Aussagen logisch zu kombinieren.

Einsteiger·Rechen- und Vergleichsoperatoren

Rechnen und zuweisen

Die üblichen Rechenzeichen sind +, -, * und /. Mit % erhältst du den Rest einer Division. Kurzformen wie += aktualisieren eine Variable.

let punkte = 10;
punkte += 5; // dasselbe wie: punkte = punkte + 5
console.log(punkte); // 15
console.log(10 % 3); // 1

Vergleiche und Logik

Vergleichsoperatoren liefern immer einen Wahrheitswert. Verwende normalerweise === und !==, damit JavaScript nicht nebenbei Datentypen umwandelt.

const alter = 18;
console.log(alter >= 18); // true
console.log(5 === "5");  // false

// UND, ODER, NICHT
const darfMitmachen = alter >= 18 && true;

&& bedeutet UND, || bedeutet ODER und ! kehrt einen Wahrheitswert um.

Merke: == vergleicht nach möglicher Typumwandlung. Nutze === für einen strikten Vergleich von Wert und Typ.
