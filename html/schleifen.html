06 / WIEDERHOLUNGEN AUTOMATISIEREN

Wiederhole
ohne Copy & Paste.

Schleifen führen einen Codeblock mehrfach aus. So kannst du Listen durchgehen oder eine Aufgabe wiederholen, solange eine Bedingung erfüllt ist.

Einsteiger·for und while

Die for-Schleife

Nutze for, wenn du weißt, wie oft etwas wiederholt werden soll. Der Kopf der Schleife enthält Startwert, Bedingung und Veränderung.

for (let nummer = 1; nummer <= 3; nummer++) {
  console.log("Runde", nummer);
}

Die Ausgabe zählt von 1 bis 3. Bei jedem Durchlauf wird nummer++ ausgeführt.

Die while-Schleife

Eine while-Schleife läuft, solange ihre Bedingung wahr ist. Achte darauf, dass sich die Bedingung irgendwann ändert — sonst entsteht eine Endlosschleife.

let restlicheVersuche = 3;
while (restlicheVersuche > 0) {
  console.log("Versuche übrig:", restlicheVersuche);
  restlicheVersuche--;
}

Für Listen sind außerdem for...of und Array-Methoden wie forEach() oft gut lesbare Alternativen.

Merke: Prüfe Startwert, Abbruchbedingung und Aktualisierung. Ein häufiger Fehler ist ein Grenzwert, der nie erreicht wird.
