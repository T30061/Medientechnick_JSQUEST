JavaScript.

JavaScript bietet verschiedene Möglichkeiten, Informationen auszugeben oder Eingaben von Benutzer:innen zu erhalten. Welche Methode geeignet ist, hängt davon ab, ob die Ausgabe für Entwickler:innen oder für normale Webseitenbesucher:innen bestimmt ist.

5 Methoden·Etwa 5 Minuten·Grundlagen

DIE ÜBERSICHT

Welche Ausgabe passt?

JAVASCRIPT BASICS
Vergleich der JavaScript-Ausgabemethoden, ihrer Zielgruppe und typischen Einsatzbereiche.
Methode Welche Art von Inhalt? Welche Benutzergruppe? Konkreter Anwendungsfall Vermeiden bei …
console.log() Texte, Zahlen, Variablen, Objekte und andere Werte zur Kontrolle und Fehlersuche. Entwickler:innen
Normale Besucher:innen sehen die Ausgabe nicht direkt. 		Variablen beim Debugging überprüfen:

console.log("Punktzahl:", punkte); 		Informationen, die für normale Webseitenbesucher:innen bestimmt sind.
alert() Kurze Textnachrichten oder wichtige Hinweise. Alle Webseitenbesucher:innen Eine kurze Meldung anzeigen:

alert("Aufgabe abgeschlossen!"); 		Häufige oder umfangreiche Meldungen, da der Dialog den Arbeitsfluss unterbricht.
document.write() Text und HTML-Code direkt in das Dokument schreiben. Alle Webseitenbesucher:innen Einfache Ausgabe in einer Lern-Demo:

document.write("<h1>Hallo!</h1>"); 		Bereits geladenen Webseiten. Bei später Verwendung kann der bestehende Dokumentinhalt überschrieben werden.
innerHTML HTML und Text innerhalb eines bestimmten HTML-Elements. Alle Webseitenbesucher:innen Den Inhalt einer Seite dynamisch verändern:

element.innerHTML = "<strong>Richtig!</strong>"; 		Ungeprüften Benutzereingaben. Die Verwendung von innerHTML mit unsicheren Daten kann XSS-Sicherheitslücken ermöglichen.
prompt() Empfängt eine Texteingabe vom Benutzer und liefert diese als String zurück. Alle Webseitenbesucher:innen Den Namen des Benutzers abfragen:

let name = prompt("Wie heißt du?"); 		Umfangreichen oder wichtigen Formulareingaben. Dafür sind normale HTML-Formulare meist besser geeignet.
✳

ZUM MITNEHMEN

Merksatz

  • 🛠️ console.log() → für Entwickler:innen und Debugging
  • 💬 alert() → kurze Nachricht an Besucher:innen
  • 📄 document.write() → einfache Ausgabe, aber mit Vorsicht
  • 🖥️ innerHTML → HTML-Inhalte dynamisch verändern
  • ⌨️ prompt() → Eingabe vom Benutzer abfragen
