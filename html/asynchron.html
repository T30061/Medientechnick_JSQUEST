19 / AUF SPÄTERES WARTEN

Asynchron:
Es dauert kurz.

Manche Aufgaben brauchen Zeit — etwa Daten aus dem Netzwerk zu laden. Asynchrones JavaScript lässt die Seite währenddessen weiterarbeiten.

Fortgeschrittene Grundlagen·Promise, async/await und fetch

Promise und async/await

Ein Promise steht für ein Ergebnis, das später verfügbar wird. Mit async und await lässt sich asynchroner Code gut lesbar schreiben. Fehler fängst du mit try...catch ab.

async function ladeDaten() {
  try {
    const antwort = await fetch("/api/infos");
    if (!antwort.ok) throw new Error("Antwort fehlgeschlagen");
    const daten = await antwort.json();
    console.log(daten);
  } catch (fehler) {
    console.error("Daten konnten nicht geladen werden", fehler);
  }
}

Was passiert hier?

  1. fetch() startet die Netzwerkanfrage und liefert ein Promise zurück.
  2. await wartet innerhalb der async-Funktion auf das Ergebnis.
  3. response.ok prüft, ob der HTTP-Status erfolgreich war.
  4. response.json() liest den Antworttext als JSON-Daten.

Merke: Netzwerkfehler und HTTP-Fehler sind nicht dasselbe. Darum neben try...catch auch response.ok prüfen.
