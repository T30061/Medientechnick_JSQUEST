12 / HTML MIT JAVASCRIPT STEUERN

Lerne das
DOM kennen.

Das DOM (Document Object Model) ist die Baumstruktur, die der Browser aus deinem HTML erstellt. JavaScript kann Elemente darin finden, verändern und neu hinzufügen.

Webentwicklung·Auswählen, ändern und erstellen

Elemente auswählen und ändern

querySelector() findet das erste Element passend zu einem CSS-Selektor. textContent setzt reinen Text; classList verwaltet CSS-Klassen.

const titel = document.querySelector("h1");
titel.textContent = "Hallo aus JavaScript!";
titel.classList.add("highlight");

Neue Elemente anlegen

Mit createElement() erstellst du ein Element, befüllst es und hängst es mit append() an einen bestehenden Bereich.

const liste = document.querySelector("ul");
const eintrag = document.createElement("li");
eintrag.textContent = "DOM üben";
liste.append(eintrag);

Für Benutzereingaben verwende textContent statt ungeprüftem innerHTML. Das schützt vor unerwartetem HTML und vielen XSS-Problemen.

Merke: JavaScript sollte erst auf Elemente zugreifen, nachdem das HTML geladen ist. Das Script-Attribut defer ist dafür eine einfache Lösung.
