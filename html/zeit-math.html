17 / NÜTZLICHE BUILT-INS

Zeit, Zufall
& Mathematik.

JavaScript bringt hilfreiche eingebaute Objekte mit. Mit Math rechnest du; mit Date arbeitest du mit Zeitpunkten und Datumsangaben.

JavaScript-Methoden·Math und Date

Das Math-Objekt

Math.round() rundet, Math.floor() rundet ab, Math.ceil() rundet auf. Math.max() findet den größten Wert.

console.log(Math.round(4.6)); // 5
console.log(Math.floor(4.9)); // 4
console.log(Math.max(3, 8, 2)); // 8

// Zufallszahl von 0 bis kleiner als 1
console.log(Math.random());

Datum und Zeit

Ein neues Date-Objekt enthält den aktuellen Zeitpunkt. getFullYear() und getMonth() liefern einzelne Bestandteile; der Monat beginnt dabei bei 0.

const jetzt = new Date();
console.log(jetzt.getFullYear());
console.log(jetzt.getMonth() + 1); // Monat 1–12
console.log(jetzt.toLocaleDateString("de-DE"));

Für eine formatierte Anzeige ist toLocaleDateString() meist besser als Datumsteile manuell zusammenzufügen.

Merke: Math.random() ist nicht für Passwörter oder sicherheitskritische Zufallswerte gedacht. Dafür gibt es die Web Crypto API.
