21 / FEHLER FINDEN UND BEHEBEN

Debugging:
Detektivarbeit.

Fehler gehören zum Programmieren. Mit der Browserkonsole, klaren Meldungen und kleinen Tests findest du Ursachen systematisch.

Gute Praxis·Konsole, try/catch und Fehlermeldungen

Die Konsole als Werkzeug

console.log() zeigt Werte, console.warn() hebt Hinweise hervor und console.error() markiert Fehler. In den Entwicklerwerkzeugen kannst du außerdem Breakpoints setzen und den Code Schritt für Schritt ausführen.

const preis = 12;
const anzahl = 3;
console.log("Zwischensumme:", preis * anzahl);

Fehler gezielt behandeln

Mit throw meldest du einen Fehler. try...catch behandelt Fehler, die während eines bestimmten Vorgangs auftreten können.

function teile(a, b) {
  if (b === 0) throw new Error("Division durch 0");
  return a / b;
}

try {
  console.log(teile(8, 0));
} catch (fehler) {
  console.error(fehler.message);
}

Ein guter Debugging-Ablauf

  1. Lies die Fehlermeldung und öffne die genannte Datei und Stelle.
  2. Prüfe Eingabewerte und Zwischenergebnisse in der Konsole.
  3. Ändere eine Sache und teste erneut.
  4. Entferne unnötige Debug-Ausgaben, wenn du fertig bist.

Merke: Eine Fehlermeldung ist ein Hinweis, kein Urteil. Suche nach der ersten Stelle, an der das Ergebnis von deiner Erwartung abweicht.
