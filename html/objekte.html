10 / ZUSAMMENGEHÖRIGES BESCHREIBEN

Objekte:
Dinge mit Details.

Ein Objekt fasst Eigenschaften und Funktionen zusammen, die zu einer Sache gehören. Damit kannst du strukturierte Daten wie ein Profil oder ein Produkt beschreiben.

Einsteiger·Eigenschaften, Methoden und Destrukturierung

Ein Objekt erstellen

Eigenschaften bestehen aus einem Schlüssel und einem Wert. Mit Punktnotation kannst du häufig verwendete Eigenschaften lesen und ändern.

const person = {
  name: "Mila",
  alter: 19,
  begruessen() {
    return `Hi, ich bin ${this.name}.`;
  }
};

console.log(person.name);
console.log(person.begruessen());

Eigenschaften sicher lesen

Mit Klammernotation kannst du auf einen Schlüssel zugreifen, der in einer Variablen steht. Destrukturierung kopiert ausgewählte Eigenschaften in eigene Variablen.

const schluessel = "alter";
console.log(person[schluessel]);

const { name, alter } = person;
console.log(`${name} ist ${alter}.`);

Eine Methode ist eine Funktion, die als Eigenschaft eines Objekts gespeichert wird. this bezieht sich in dieser Methode auf das Objekt, über das sie aufgerufen wurde.

Merke: Arrays eignen sich für geordnete Listen; Objekte eignen sich für benannte Eigenschaften eines einzelnen Eintrags.
